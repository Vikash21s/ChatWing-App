# 💬 ChatWing - Real-Time Chat Application

ChatWing is a modern, fast, and lightweight real-time chat application built with **Flutter** and powered by **Firebase**. It supports one-on-one and group messaging with a clean UI, smooth experience, and real-time sync.

> 📱 Built for Android using Flutter SDK  
> 🔐 End-to-end encrypted architecture (coming soon)  
> 🔧 Backend powered by Firebase Authentication & Realtime Database

---

## 🚀 Features

- 💬 Real-time one-to-one chat
- 👥 Group messaging support
- 🔐 Firebase Authentication (Login/SignUp)
- 🔔 Instant message sync with Realtime Database
- 📱 Smooth and responsive UI built in Flutter
- 🕵️ Typing indicator (coming soon)
- 📷 Media sharing (coming soon)
